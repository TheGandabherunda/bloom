Bloom is a shared music player — create a room, share the code, and everyone hears the same song at the same time. No sign-up. No server. When everyone leaves, the room disappears.

## What you can do

- Create or join a listening room with a short room code
- Play music in perfect sync with everyone
- Chat, send GIFs, and see real-time lyrics
- Suggest songs — the room votes to add them to the queue
- Host controls playback; 50%+ peer votes auto-add a track

## Running locally

Requires [Node.js](https://nodejs.org) v20+.

```bash
git clone https://github.com/TheGandabherunda/bloom.git
cd bloom
npm install
npm run dev
```
